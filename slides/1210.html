Forecasting the Fed's Next Move

The Agent Model Approach

Prior Research vs. Enhanced vs. Agent Strategy

Part 1: Introduction

Purpose & Importance

Research Purpose

Goal: Reliably forecast U.S. Fed interest rate decisions (Raise, Hold, Lower) using a Multi-Modal approach.

  • Problem: Traditional models miss nuanced textual signals.
  • Solution: Combine Macroeconomic Indicators + Textual Sentiment (Fed Communications).

Part 2: Prior Research

Method 1 (The Baseline)

Method 1: Baseline Architecture

XGBoost Classifier trained on:

1. Economic Data

Standardized indicators (CPI, Unemployment, etc.)

2. Text Features

TF-IDF Vectors + LM Sentiment Scores.

Performance: AUC 0.8535. Good, but struggled with minority classes (Rate Cuts).

Part 3: Enhanced Methodology

Improving Feature Engineering

Key Improvements

  • Text: Added Bi-grams (e.g., "inflation target") to capture context.
  • Data: Added 3M/6M Rolling Averages to capture economic trends.
  • Tuning: RandomizedSearchCV for dynamic hyperparameter optimization.

Result: AUC improved to 0.8671.

Part 4: The Agent Model Strategy

A Stacking Ensemble Approach

The "Agent" Concept

Instead of relying on one model, we built a Stacking Ensemble.

Level 1: Specialist Agents

Diverse models trained separately:

  • Logistic Regression (The Conservative)
  • Random Forest (The Generalist)
  • XGBoost (The Trend Spotter)

Level 2: Decision Agent

A Meta-Learner (Logistic Regression) that takes the opinions (probability predictions) of the specialists + economic data to make the final call.

Motivation: Why use Agents?

1. Diversity of Opinion

Single models have blind spots. Linear models miss non-linear trends; Tree models can overfit. Agents cover each other's weaknesses.

2. Robustness to Imbalance

"Rate Cuts" are rare events. By stacking models, the Decision Agent learns to trust the specific specialist that is best at spotting these rare signals.

Why did it perform better?

  • Superior Ranking: The Agent model achieved an AUC of 0.8735, the highest of all experiments.
  • Perfect Recall on "Cuts":

    Recall for Class -1 (Lower): 1.00

    Unlike previous models that ignored rate cuts, the Decision Agent successfully identified 100% of cut instances in the test set.

  • Trust Calibration: The meta-learner learned to weigh the "confidence" of each agent, reducing false alarms on the "Hold" class.
